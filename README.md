# AI Test Case Generator

AI-powered QA test case generator using a local LLM through Ollama.

## Features

- Generate QA test cases using AI
- Local LLM inference with phi3
- Node.js backend API
- Simple frontend UI
- Functional / Regression / API / Security test generation

---

## Tech Stack

- HTML
- JavaScript
- Node.js
- Express
- Ollama
- phi3 model

---

## Architecture

Frontend (Browser UI)
↓
Node.js Backend API
↓
Ollama Local AI Runtime
↓
phi3 Model Inference
